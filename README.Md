# Cognitive Aging in NHANES

## Overview

This project examines the relationships among physical activity, depressive symptoms, and cognitive performance among U.S. adults aged 60 and older using data from the 2011–2014 National Health and Nutrition Examination Survey (NHANES).

A Structural Equation Model (SEM), Confirmatory Factor Analysis (CFA) tests whether depressive symptoms partly mediate the association between recreational physical activity and cognitive functioning.

## Research Questions

1. Is greater physical activity associated with fewer depressive symptoms?
2. Are fewer depressive symptoms associated with better cognitive performance?
3. Is physical activity indirectly associated with cognition through depressive symptoms?

## Planned Measures

- **Exposure:** Recreational physical activity
- **Mediator:** PHQ-9 depressive-symptom score
- **Outcome:** Latent cognitive-function factor measured using available NHANES cognitive tests
- **Covariates:** Age, sex, and educational attainment

## Planned Analysis

Analyses will be conducted in R using descriptive statistics, data visualization, and structural equation modeling. Appropriate NHANES sampling weights will be incorporated where feasible.

## Data Source

National Center for Health Statistics. National Health and Nutrition Examination Survey, 2011–2014.
